# 📊 Sales Performance Dashboard – Excel

## 📌 Project Overview

This project is an interactive **Sales Performance Dashboard built in Microsoft Excel**.

The main objective of this project is to transform raw sales data into meaningful business insights using **PivotTables, PivotCharts, Slicers, Timeline Filters, and KPI Cards**.

The dashboard helps analyze sales performance across different months, regions, product categories, customer types, and sales channels.

---

## 🎯 Objectives

- Analyze overall sales performance
- Track monthly revenue trends
- Compare revenue across different regions
- Identify top-performing product categories
- Analyze sales by different sales channels
- Identify the top 5 products by revenue
- Make the dashboard interactive using slicers and timeline filters

## 📊 Dashboard Features

### KPI Metrics
The dashboard displays:

- 💰 Total Revenue
- 🛒 Total Orders
- 📦 Quantity Sold
- 💵 Average Order Value

### Interactive Filters

Users can filter the dashboard using:

- Region
- Product Category
- Customer Type
- Sales Channel
- Year
- Quarter
- Month
- Day

---

## 🔍 Key Insights

Some important insights identified from the dashboard:

- **June** recorded the highest monthly revenue at approximately **373.9K**.
- **Computers** generated the highest revenue among product categories, contributing more than **2.05M**.
- **Central Region** generated the highest regional revenue at approximately **802.6K**.
- **Gaming Laptop** was the top-performing product by revenue, generating approximately **666K**.
- The dashboard provides a clear comparison of revenue across different **sales channels and customer types**.
